CORE FUNCTIONALITY
================================================================================

PURPOSE:
  Enable automatic trait bound generation for generic types in
  #[derive(CapsuleSerialize)] macros. Users no longer need to manually
  specify <T: CapsuleSerialize> bounds.

BEFORE (Manual):
  #[derive(CapsuleSerialize)]
  struct Wrapper<T: CapsuleSerialize> {
      value: T,
  }

AFTER (GenericConstraintCapsule):
  #[derive(CapsuleSerialize)]
  struct Wrapper<T> {
      value: T,
  }
  // Macro generates: impl<T: CapsuleSerialize> FixedPointSerialize for Wrapper<T>

KEY CAPABILITIES:
  ✅ Extract generic parameter names from Generics
  ✅ Add CapsuleSerialize bounds to all type params
  ✅ Add CapsuleDeserialize bounds to all type params
  ✅ Preserve existing bounds and where clauses
  ✅ Merge custom where clause predicates
  ✅ Detect generic vs non-generic structs
  ✅ Generate qualified generic parameter lists for impl blocks
  ✅ Format bounds as human-readable strings

EXAMPLES:
  Input:  <T>
  Output: <T: CapsuleSerialize>

  Input:  <T: Clone, U: Default>
  Output: <T: Clone + CapsuleSerialize, U: Default + CapsuleSerialize>

  Input:  <T> where T: Clone
  Output: <T: Clone + CapsuleSerialize> where T: Clone, T: CapsuleSerialize
