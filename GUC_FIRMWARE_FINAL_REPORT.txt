ARCHITECTURE & DESIGN:

T8 Network Tier Capsule
  - Purpose: Lockfree communication with Intel GPU firmware
  - Coordination: DualAtomicU64 (primary + secondary fields)
  - Memory: 256B cache-aligned (prevent false-sharing on multi-core)
  - Initialization: Zero-allocation (stack-based atomics)

Memory Layout (256 bytes):
  Offset    Field              Size    Purpose
  ------    -----              ----    -------
  0         primary            8B      Doorbell(16) | State(8) | Gen(32)
  8         secondary          8B      Response(16) | BatchCount(16) | Gen(32)
  16        h2g_head           8B      Host-to-GPU queue head
  24        h2g_tail           8B      Host-to-GPU queue tail
  32        g2h_response       8B      GPU-to-Host response tracking
  40        _padding           216B    Cache-line padding to 256B

State Machine (4 States):
  Idle (0)       → Ringing (1) → Waiting (2) → Complete (3) → [reset]
  No submissions → Doorbell signaled → Awaiting response → Response received

Core Operations (6):

  1. new() -> GuCFirmwareCapsule
     - Creates zero-initialized capsule
     - All atomic fields set to 0
     - Zero allocation, 256B cache-aligned

  2. ring_doorbell(&[u32]) -> GuCResult<DoorbellHandle>
     - Submits batch to firmware
     - Atomic CAS loop with exponential backoff
     - Performance: <1μs latency
     - Returns doorbell index + generation

  3. poll_response() -> GuCResult<Option<FirmwareResponse>>
     - Non-blocking firmware response check
     - Single Acquire load
     - Performance: <50ns latency
     - Returns response status or None if pending

  4. submit_workload(&[u32]) -> GuCResult<WorkloadHandle>
     - High-level: ring_doorbell + poll with timeout
     - Validates context IDs (16-bit range)
     - Polls for ~10μs (10,000 iterations)
     - Returns workload handle with context count

  5. get_status() -> FirmwareStatus
     - Atomic snapshot of state + response
     - Non-blocking query operation
     - Performance: <50ns latency

  6. snapshot() -> u64
     - Single atomic load of primary field
     - For monitoring/debugging
     - Performance: <50ns latency

Error Types (5):
  - DoorbellTimeout: CAS loop contention or firmware unresponsive
  - InvalidContextId: Out-of-range or empty context array
  - QueueFull: Firmware queue exhausted (reserved for future)
  - InvalidStateTransition: FSM violation (e.g., ring when not Idle)
  - FirmwareError: Firmware error response (status = 4)

COCA COMPLIANCE (Computational Capsule):

✅ 100% Lockfree
   - Zero mutex/RwLock (forbidden by COCA mandate)
   - All coordination via atomic operations only

   - Padding field ensures exact alignment

   - Exponential backoff prevents livelock
   - No dynamic allocation in hot path
