TECHNICAL ARCHITECTURE
================================================================================

Batch State FSM:
  Idle → Recording → Submitting → Submitted
  (with generation counter for ABA prevention)

Worker Thread Coordination:
  - 8 worker threads maximum (fixed-size array)
  - Per-thread atomic state tracking (64B-aligned)
  - Atomic command counting (saturating increment)

Atomic Bit-Packing (DualAtomicU64):
  Primary:
    - State (4 bits): 0=Idle, 1=Recording, 2=Submitting, 3=Submitted
    - ActiveThreads (4 bits): Count of registered threads
    - Generation (8 bits): ABA prevention counter
    - Reserved (48 bits): For future expansion

  Secondary:
    - TotalCommands (32 bits): Command accumulator
    - Generation (32 bits): Matches primary generation

Memory Ordering:
  - Acquire/Release for visibility across threads
  - Sequential consistency for batch operations
  - Lock-free wait-free algorithms throughout
