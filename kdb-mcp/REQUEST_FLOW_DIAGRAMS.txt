4. AUDIT TRAIL STRUCTURE

AuditLogCapsule (32 KB ring buffer):

┌─ Layout:                                                                    │
│ ├─ entries: UnsafeCell<[AuditEntry; 512]>  // 512 × 64 bytes = 32,768 B │
│ ├─ head: AtomicU64                         // Write position (lockfree)   │
│ └─ padding: [u8; 56]                       // Cache line padding          │
│                                                                              │
├─ AuditEntry (64 bytes):                                                    │
│ ├─ timestamp_ns: u64                       // Absolute timestamp          │
│ ├─ request_id: u64                         // Unique request identifier   │
│ ├─ tool_id: u64                            // Tool that was called        │
│ ├─ user_hash: u64                          // Hashed API key             │
│ ├─ latency_ns: u64                         // Request latency in ns       │
│ ├─ success: u64                            // 1 = success, 0 = failure    │
│ └─ padding: [u8; 16]                       // Cache alignment             │
│                                                                              │
├─ Recording (lockfree):                                                     │
│   let index = head.fetch_add(1, Ordering::Relaxed) & 0x1FF;  // & 511    │
│   entries[index] = AuditEntry { ... };                                     │
│                                                                              │
├─ All Recording Points:                                                     │
