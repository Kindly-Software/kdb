TROUBLESHOOTING
================================================================================

Problem: Connection refused on remote
  Solution: Check SSH connectivity
  Command: ssh samuel@192.168.0.38 "hostname"

Problem: Binary not found on remote
  Solution: Verify deployment path
  Command: ssh samuel@192.168.0.38 "ls ~/mcp_servers/atomic_mcp_server/bin/"

Problem: Permission denied on remote
  Solution: Fix executable bit
  Command: ssh samuel@192.168.0.38 "chmod +x ~/mcp_servers/.../mcp_debug_server"

Problem: High latency on remote
  Expected: SSH adds ~200ms overhead (documented)
  Actual processing: <2μs (excellent)

Problem: Authentication required error
  Expected: All requests require API key
  Demo key: demo-key-mcp-2025 (valid until 2030)
