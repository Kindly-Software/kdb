  ✅ StdioTransportCapsule (well-designed)

PROTOCOL COMPLIANCE: BROKEN ❌
  ❌ Issue #1: Missing `notifications/initialized` handler (CRITICAL)
  ❌ Issue #2: Excessive startup logging to stderr (HIGH)
  ❌ Issue #3: No stdout.flush() after responses (CRITICAL)
  ❌ Issue #4: No protocol version validation (MEDIUM)

ROOT CAUSE: The MCP protocol requires a 3-step handshake:
  1. Client sends initialize request
  2. Server responds with initialize response
  3. Client sends notifications/initialized notification
     ← Your server doesn't handle this (MISSING)

When Claude Code doesn't get acknowledgment of step 3, it:
  - Waits for up to 5 seconds
  - Doesn't proceed to tools/list
  - Eventually times out
  - Disconnects with "Failed to reconnect"

MANUAL TESTING WORKS: You can send JSON to stdin and get responses
CLAUDE CODE FAILS: Timing/protocol issues prevent connection
