Vec<MinHashSignatureCapsule>

  5. Pure functional parallelism (no shared state)

5 Core Assumptions (All Verified):

1. MINHASH_DETERMINISTIC
   Assumption: Same tokens → same signature
   Verification: Fixed seed (0x1234), property-tested with 1000+ inputs
   Risk level: NEGLIGIBLE (hardware constant)
   Test: prop_deterministic_signatures()

2. BATCH_INDEPENDENCE
   Assumption: Each batch processes independently (no shared mutable state)
   Verification: Pure parallel map (rayon work-stealing)
   Risk level: NEGLIGIBLE (proven by rayon)
   Test: prop_order_preservation()

3. TOKENIZE_DETERMINISTIC
   Assumption: tokenize() is pure function (no global state, no randomness)
   Verification: Whitespace split + lowercase (deterministic)
   Risk level: NEGLIGIBLE (immutable input)
   Test: prop_tokenization_consistency()

4. CACHE_ALIGNED
   Assumption: 64-byte alignment prevents false sharing
   Verification: #[repr(C, align(64))] + runtime pointer check
   Risk level: NEGLIGIBLE (compile-time enforced)
   Test: test_cache_alignment()

   Assumption: 16K docs × 256 bytes = 4 MB fits in L3 cache (8-32 MB)

   Risk level: LOW (conservative 50% margin)
