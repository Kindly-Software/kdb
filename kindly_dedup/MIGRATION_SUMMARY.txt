WHAT CHANGED IN CODE
================================================================================

BEFORE (rayon):
  let signatures: Vec<_> = batch
      .par_iter()
      .map(|text| Self::compute_signature_for_text(text))
      .collect();

AFTER (atomic_capsule):
  let signatures: Vec<_> = batch
      .into_par_iter()
      .map(|text| Self::compute_signature_for_text(&text))
      .collect();

KEY DIFFERENCES:
  1. Import: rayon::prelude::* → atomic_capsule::parallel::IntoParallelIterator
  2. API: .par_iter() → .into_par_iter() (consumes Vec instead of borrowing)
  3. Closure: Take reference explicitly (&text)
