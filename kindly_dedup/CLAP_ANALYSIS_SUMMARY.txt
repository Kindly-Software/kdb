RECOMMENDATION
==============

PRIMARY: KEEP CLAP (RECOMMENDED)
────────────────────────────────
Rationale:
• Complex CLI (6 subcommands, 30+ flags) benefits from derive macros
• Compile-time verification catches errors early
• Auto-generated help documentation (saves 100+ LOC)
• 8 transitive crates is negligible cost (50KB binary, 1-2s build)
• Current design already isolates clap to optional feature
• Widely maintained, stable crate with no breaking changes expected

Cost:        8 transitive crates, 50KB binary, 1-2s build
Benefit:     Type-safe, self-documenting, compile-time verified
ROI:         Strongly positive (keep current design)
