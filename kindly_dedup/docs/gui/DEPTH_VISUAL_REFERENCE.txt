┌───────────────────────────────────────────────────────────────────────────────┐
│                            USAGE GUIDELINES                                   │
└───────────────────────────────────────────────────────────────────────────────┘

USE CARDBASE (85%) FOR:
✅ Main application cards
   - File input card
   - Settings card
   - Results card
   - Progress card

USE CARDNESTED (90%) FOR:
✅ Nested sections within cards
   - Drag-drop zones
   - Metrics panels
   - Feature badges
   - Error/warning boxes

USE CARDCONTENT (100%) FOR:
✅ Interactive elements (no GlassmorphicCard wrapper)
   - Buttons
   - Sliders
   - Text labels
   - Input fields

AVOID:
❌ Using CardContent for entire cards (should be 100% opaque)
❌ Mixing depth inconsistently (child deeper than parent)
❌ Over-nesting (max 2-3 depth levels for readability)

Code:
```rust
use crate::gui::depth::{DepthLayer, guidelines};

// Main card (default)
GlassmorphicCard::new(content).view()

// Nested section
GlassmorphicCard::new(content)
    .with_depth(DepthLayer::CardNested)
    .view()

// Use guidelines
let depth = guidelines::MAIN_CARD;      // CardBase
let depth = guidelines::NESTED_SECTION; // CardNested
let depth = guidelines::BADGE;          // CardNested
```
