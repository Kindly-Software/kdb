TECHNICAL SPECIFICATIONS
================================================================================

ARCHITECTURE:
  OutputAggregatorCapsule (128B fixed, 128B aligned)
  ├── Config (64B): num_workers, buffer_capacity
  ├── Coordination (64B): next_worker_to_drain, total_signatures, generation
  └── Per-worker buffers: Vec<WorkerOutputBuffer> (heap)

  WorkerOutputBuffer (128B header, heap signatures, 128B aligned)
  ├── State (64B): head, tail, capacity, mask (atomics)
  ├── Signatures: UnsafeCell<Vec<MinHashSignatureCapsule>>
  └── Padding (64B)

MEMORY ORDERING:
  Push (worker):   Relaxed (no coordination, worker-local write)
  Drain (main):    Acquire (synchronize with worker writes)
  Update (main):   Release (allow worker to see consumed indices)

PERFORMANCE:
  • Push: <20ns (Relaxed CAS on head)
  • Drain: <10μs per worker (Acquire load + sequential extraction)
  • Backpressure: <1ns (atomic load)
  • Memory: 128B fixed + 128B per worker + capacity × 256B per worker

LOCKFREE GUARANTEE:
  ✓ No mutex/RwLock
  ✓ No condition variables
  ✓ Per-worker isolation (zero contention)
  ✓ Cache-aligned (128 bytes)
  ✓ Pure atomic coordination

MEMORY SAFETY ANALYSIS
================================================================================

UnsafeCell<Vec> Usage:
  ✓ Worker threads have exclusive write regions (head-based)
  ✓ Main thread has exclusive read regions (tail-based)
  ✓ Non-overlapping access via atomic head/tail coordination
  ✓ Acquire/Release memory ordering ensures visibility

Proof of Safety:
  • If head == tail: buffer is empty (no conflict)
  • If head > tail: unread data in range [tail..head)
  • If next_head == tail: buffer is full (backpressure)
  • Each thread accesses disjoint indices
