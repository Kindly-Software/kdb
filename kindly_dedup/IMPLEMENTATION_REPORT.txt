                      PARALLEL PROCESSING PIPELINE
================================================================================

Phase 2 Execution Flow:

    1. Create JobCoordinatorCapsule (Arc for thread-safe sharing)
    2. Distribute chunks to rayon thread pool
    3. Each worker:
       a) Submit job (atomic increment)
       b) Time execution (Instant::now())
       c) Create independent UniversalDedupPipeline
       d) Process chunk (5-phase state machine)
       e) Extract clusters
       f) Mark complete or fail (atomic increment)
    4. Collect results from all workers
    5. Verify completion status
    6. Merge results (Phase 3)
    7. Output final clusters

ERROR HANDLING:
- Graceful degradation: Failed chunks return empty result
- Error logged to stderr with context
- Job marked failed in coordinator
- Pipeline continues with remaining chunks
- Final error if any job failed
