TECHNICAL NOTES
================================================================================

Stack Size Issue:
  The DebuggerCapsule is 1.09 MB, which exceeds the default Rust stack
  (typically 2 MB on Linux). Tests must be run with:
    export RUST_MIN_STACK=8388608  # 8 MB minimum

  This environment variable is documented in .cargo/config.toml but must
  be explicitly set when running tests.

Linux-Only Tests:
  Ptrace tests use #[cfg(target_os = "linux")] for conditional compilation.
  Non-Linux platforms run a placeholder test instead.

Performance Targets (B32 Validated):
  - Snapshot capture: <10 microseconds (fast path: 5-8 ns)
  - Breakpoint coordination: <100 nanoseconds
  - Ring buffer capacity: 3,072 entries
  - Memory growth under load: bounded (< 100 MB for 10K snapshots)

ASSUM Safety:
  All assumptions documented with #ASSUME_ tags:
  - LOCKFREE_COORDINATION: All atomics, no mutexes
  - CONSISTENT_STATE: Snapshots remain consistent
  - NO_DATA_LOSS: Events recorded atomically
  - MONOTONIC_SNAPSHOTS: Snapshot IDs always increase
  - MEMORY_BOUNDED: Memory usage within limits
