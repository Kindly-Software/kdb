CORE ALGORITHM (RFC 9002 §6.2)
────────────────────────────────────────────────────────────────────────────

Formula:  PTO = smoothed_rtt + max(4×rttvar, 1ms) + max_ack_delay

Where:
  - smoothed_rtt: Exponential moving average (EWMA 7/8 old + 1/8 new)
  - rttvar: Mean absolute deviation (EWMA 3/4 old + 1/4 diff)
  - max_ack_delay: Peer's announced maximum ACK delay
  - max(4×rttvar, 1ms): Variance component with 1ms floor

MEMORY LAYOUT (DualAtomicU64)
────────────────────────────────────────────────────────────────────────────

Offset 0-7:   AtomicU64 primary
  ├─ Bits 32-63: smoothed_rtt_q16 (u32, Q16.16 fixed-point)
  └─ Bits 0-31:  rttvar_q16 (u32, Q16.16 fixed-point)

Offset 8-15:  AtomicU64 secondary
  ├─ Bits 32-63: pto_q16 (u32, Q16.16, computed)
  └─ Bits 0-31:  max_ack_delay_q16 (u32, Q16.16)

Offset 16-63: Padding (48 bytes) to complete cache line

FIXED-POINT Q16.16 ENCODING
────────────────────────────────────────────────────────────────────────────

Format:    [Integer: 16 bits] [Fractional: 16 bits]
Range:     0.0 to 65535.99998 milliseconds
Precision: 0.0000153 ms (15.3 microseconds)
1.0 ms  =  65536 (2^16)
0.5 ms  =  32768 (2^15)
Multiply: (a * b) >> 16  (for Q16.16 × Q16.16)

API REFERENCE
────────────────────────────────────────────────────────────────────────────

// Constructor
fn new() -> Self
  - Initializes RFC 9002 defaults: 333ms smoothed_rtt, 166ms rttvar

// Update Operations
fn update_smoothed_rtt(&self, rtt_q16: u32)
  - EWMA: (7 × smoothed_rtt + latest_rtt) / 8

fn update_rttvar(&self, rtt_q16: u32)
  - MAD: (3 × rttvar + |smoothed_rtt - latest_rtt|) / 4

fn set_max_ack_delay(&self, delay_q16: u32)
  - Sets peer's max ACK delay

// Computation
fn compute_pto(&self) -> u32
  - Computes PTO = smoothed_rtt + max(4×rttvar, 1ms) + max_ack_delay
  - Caches result in secondary atomic

// Fast Queries (<5ns)
fn get_pto(&self) -> u32              // Cached PTO value
fn get_smoothed_rtt(&self) -> u32     // Current smoothed RTT
fn get_rttvar(&self) -> u32           // Current RTTVAR
fn get_max_ack_delay(&self) -> u32    // Current max ACK delay

use atomic_capsule::quic::RttEstimatorCapsule;

// Create estimator with RFC defaults

// Update based on RTT samples (Q16.16 format)

// Compute PTO
