Q16.16 FIXED-POINT ARITHMETIC GUARANTEE
================================================================================

Format:
  - 32-bit signed integer
  - Upper 16 bits: Integer part (-32,768 to +32,767)
  - Lower 16 bits: Fractional part (0/65,536 to 65,535/65,536)
  - Precision: 1/65,536 ≈ 0.0000153

Operations:
  - Multiply: (a × b) >> 16 (with 0.5 rounding)
  - Divide: (a << 16) / b (for inverse scales)
  - Conversion: float ↔ fixed via × 65536 or ÷ 65536

Determinism:
  - Integer-only arithmetic (no floating-point)
  - Bit-exact results across all platforms (x86_64, aarch64, WASM)
  - Reproducible over time (encode Nov 2025 = decode Jan 2026)
  - 0% chance of platform drift


ARCHITECTURE HIGHLIGHTS
================================================================================

Memory Layout (128 bytes):
  Offset  Field                      Size  Purpose
  ------  -----                      ----  -------
  0       qp_state (AtomicU64)       8B    [qp(8)|dc_delta(6)|ac_delta(6)|gen(12)|reserved(32)]
  8       quantization_matrix[0..8]  64B   Q16.16 scale factors (8 frequency bands)
  72      dequant_matrix[0..8]       64B   Q16.16 inverse scales
  136     [padding to 128B cache alignment]

Design Rationale:
  - DualAtomicU64 bit-packing: Enables <50ns CAS state updates
  - 8-frequency bands: Follows AV1 specification (§4.8.4)
  - Generation counter: Prevents TOCTOU in concurrent scenarios
  - Cache alignment: 128B = 2 × 64B cache lines (prevents false sharing)

Thread Safety:
  - All state updates via atomic CAS (compare-and-swap)
  - Acquire/Release memory ordering ensures visibility
  - Zero mutex/RwLock (100% lockfree)
  - Concurrent quantization safe (read-only operations after initialization)
