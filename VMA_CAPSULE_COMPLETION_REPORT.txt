================================================================================
                            ARCHITECTURE SUMMARY
================================================================================

Memory Layout (64 bytes total):
   Primary Atomic:   GttOffset(40) | Pinned(1) | Flags(7) | Gen(16)
   Secondary Atomic: Size(32) | RefCount(16) | Gen(16)
   VmaState:         last_update_ns(u64) | counters(u32 × 3) | reserved(4B)
   VmaFlags:         1 byte (control flags)
   Padding:          23 bytes (alignment)

Coordination Model:
   - DualAtomicU64 for independent state updates
   - Generation counters (16-bit) for ABA prevention
   - Acquire/Release ordering for visibility
   - Relaxed loads for local reads (is_pinned)

Error Handling:
   AlreadyPinned, NotPinned, InvalidOffset, InvalidSize, SizeOverflow,
   AddressSpaceExhausted, MisalignedOffset, GenerationOverflow
