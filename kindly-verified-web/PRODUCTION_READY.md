## Deployment Guide

### Prerequisites

1. **Rust Toolchain**: Nightly (for portable_simd, const_fn_floating_point)
2. **Trunk**: WASM bundler (`cargo install trunk`)
3. **wasm32 Target**: `rustup target add wasm32-unknown-unknown`
4. **Fly.io CLI**: For deployment (`curl -L https://fly.io/install.sh | sh`)

### Local Development

```bash
# Clone repository
cd /home/samuel/Primitives/kindly-verified-web

# Development server (hot reload)
trunk serve --open

# Access at http://localhost:8080
```

### Production Build

```bash
# Build optimized WASM bundle
trunk build --release

# Output: dist/
# - kindly-verified-web-*.wasm (458KB)
# - kindly-verified-web-*.js (49KB)
# - index.html (7KB)

# Verify bundle sizes
ls -lh dist/
```

### Deployment to Fly.io

```bash
# Login to Fly.io
fly auth login

# Create app (first time only)
fly apps create kindly-verified-web

# Deploy
fly deploy --region sjc

# Set secrets (if needed)
fly secrets set STRIPE_API_KEY=sk_live_...

# Check status
fly status

# View logs
fly logs

# Open in browser
fly open
```

### Custom Domain Setup

```bash
# Add custom domain
fly certs add kindly-verified.com

# Get DNS records
fly certs show kindly-verified.com

# Add CNAME record in your DNS:
# kindly-verified.com CNAME kindly-verified-web.fly.dev

# Verify SSL
fly certs check kindly-verified.com
```
