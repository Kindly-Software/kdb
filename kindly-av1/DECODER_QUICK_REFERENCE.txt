================================================================================
ARCHITECTURE OVERVIEW
================================================================================

Three Parallel Decoder Pipelines (Star Pattern):
┌──────────────────────────────────────────────────────────────────┐
│ Bitstream → SPS/PPS → Entropy Decoder → Macroblock Loop          │
├──────────────────────────────────────────────────────────────────┤
│ Each Macroblock/Block decodes:                                   │
│  1. Intra or Inter prediction (based on MB type)                 │
│  2. Inverse transform (IDCT/ADST/etc)                            │
│  3. In-loop filtering (deblock, CDEF, LRF)                       │
│  4. Reference frame update (for next MB/frame)                   │
└──────────────────────────────────────────────────────────────────┘

Each codec has independent star pattern - NO cross-codec dependencies.
