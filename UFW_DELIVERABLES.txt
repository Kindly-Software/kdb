================================================================================
TROUBLESHOOTING
================================================================================

SSH Locked Out:
  → Physical access needed
  → Boot into GRUB, drop to root shell
  → Run: sudo ufw disable

Port Already in Use:
  → Check: sudo lsof -i :PORT
  → Stop conflicting service
  → Or configure UFW to allow different port

Rate Limit Too Strict:
  → sudo ufw delete 2  (delete rule #2)
  → sudo ufw limit 22/tcp  (re-add with new parameters)

Too Many Logs:
  → sudo ufw logging low  (reduce verbosity)
