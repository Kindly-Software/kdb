ISSUE 1: CLIPPY PLUGIN LOADING MECHANISM ⚠️ CRITICAL
------------------------------------------------------------------------
Severity: Critical
Impact:   Prevents standard UI testing
Status:   Documented with solution (integration testing)

Description:
  Custom clippy plugins using rustc_private can ONLY be loaded through
  the clippy driver, not through rustc directly. This is a fundamental
  architectural limitation of the Rust compiler.

Evidence:
  # This does NOT work:
  rustc --extern clippy_capsule_verify=plugin.so test.rs
  
  # This is what's needed:
  clippy-driver --plugin clippy_capsule_verify test.rs
  # OR integration testing (recommended)

Implication:
  Standard trybuild and rustc-based UI testing cannot work for custom
  clippy plugins. Requires different approach (integration tests).

Solution:
  Implement integration testing with mini-crates per category (4-6 hours).
  Fully documented in TESTING_GUIDE.md § Solution 1.


ISSUE 2: UNNECESSARY TEST DEPENDENCIES ⚠️ HIGH
------------------------------------------------------------------------
Severity: High
Impact:   30/40 tests fail to compile
Status:   Fixable via ./scripts/fix_test_files.sh

Description:
  Many tests include 'extern crate rustc_span' which:
  - Is not needed for lint testing
  - Is not available outside rustc/clippy internals
  - Causes immediate compilation failure

Fix:
