## What Was Built

A Clippy lint that detects padding fields with incorrect size calculations:

BAD:
```rust
#[repr(C, align(64))]
struct BadCapsule {
    state: AtomicU64,      // 8 bytes
    _padding: [u8; 50],    // WRONG! Should be 56
}  // Total: 58 bytes (not 64!) → False sharing!
```

GOOD:
```rust
#[repr(C, align(64))]
struct GoodCapsule {
    state: AtomicU64,
    _padding: [u8; 56],    // CORRECT!
}  // Total: 64 bytes ✓
```

## Detection Algorithm

1. Find padding field(s) (_padding, _pad, _pad*)
2. Calculate size without padding
3. Calculate required padding: align - (size_without_padding % align)
4. Compare actual vs required padding
5. Emit diagnostic if mismatch
