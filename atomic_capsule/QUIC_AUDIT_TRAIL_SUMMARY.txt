ARCHITECTURE
================================================================================

TIER: T0 Auditable (Q34 compliance: SOX/SOC2/GDPR/HIPAA)
SIZE: 256 bytes, 256-byte cache-aligned
PERFORMANCE: <50ns append, <1μs verify, <500ns export

Ring Buffer:
  - 16 events × 8 bytes = 128 bytes
  - Atomic head/tail indices (8 bytes each)
  - Hash chain accumulator (8 bytes)
  - Padding for alignment (104 bytes)
  Total: 256 bytes (4 cache lines)

Event Types (10):
  0 = ConnectionEstablished    5 = CongestionEvent
  1 = ConnectionMigrated       6 = TlsHandshakeComplete
  2 = ConnectionClosed         7 = StreamCreated
  3 = PacketLost               8 = StreamClosed
  4 = FlowControlViolation     9 = AckReceived

Hash Chain (Tamper Detection):
  hash = crc64(prev_hash || timestamp || event_type || cid_hash || metadata)
  - Immutable: breaking chain indicates tampering
  - Verifiable: walk entire chain, recompute hashes
  - Deterministic: CRC64 lookup table, no randomness

USAGE EXAMPLE
================================================================================

// Create audit trail
let audit = QuicAuditTrailCapsule::new();

// Append events
audit.append_event(
    AuditEventType::ConnectionEstablished,
    cid_hash,
    0
)?;

audit.append_event(
    AuditEventType::PacketLost,
    cid_hash,
    packet_number as u16
)?;

// Verify integrity before export
audit.verify_hash_chain()?;

// Export for compliance reporting
let events = audit.export_events()?;
for event in events {
    println!("{}@{}ns: {}", event.event_type, event.timestamp_ns, event.metadata);
}
