════════════════════════════════════════════════════════════════════════════════

   ├─ Lookup connection (T4 batch, ~1.5μs)
   ├─ Dispatch frames (T1 updates, ~1μs)
   └─ Audit event (T0 hash-chain, <500ns)

2. ACK PROCESSING (~2μs)
   ├─ Guard: Validate ACK ranges not empty
   ├─ Process ACK ranges (T4 batch, ~1μs)
   ├─ Update RTT (T1+T3 Karn's, <50ns)
   ├─ Update congestion window (T1+T3 CUBIC, <50ns)
   ├─ Update pacing (T1+T3, <50ns)
   └─ Audit event (T0, <50ns)

3. STREAM DATA (~1μs)
   ├─ Guard: Validate payload size (<16K)
   ├─ Lookup stream (T4, ~100ns)
   ├─ Check stream flow control (T1+T3, ~20ns)
   ├─ Check connection flow control (T1+T3, ~20ns)
   ├─ Deliver payload (buffer, ~100ns)
   └─ Update metrics (Relaxed, ~10ns)

4. CONNECTION CLOSE (~50μs)
   ├─ Guard: Validate CID length (8-20 bytes)
   ├─ Lookup connection (T4, ~100ns)
   ├─ Drain inflight packets (T5, ~20μs)
   ├─ Close streams (T4, ~15μs)
   ├─ Free resources (T1, ~10μs)
   ├─ Decrement counter (Relaxed, <10ns)
   └─ Audit event (T0, <50ns)
