USAGE QUICK START

FILTER (Predicate-based selection):
  let filter = StreamingFilterCapsule::new(|x: &u64| *x > 100);
  filter.push(50);   // Filtered out
  filter.push(150);  // Passes
  assert_eq!(filter.output_count(), 1);

MAP (Type transformation):
  let mapper = StreamingMapCapsule::new(|x: &u64| *x as f64);
  mapper.push(100u64);
  mapper.push(200u64);
  let all = mapper.consume();  // vec![100.0, 200.0]

REDUCE (Incremental aggregation):
  let reducer = StreamingReduceCapsule::new(0u64, |acc, x| acc + x);
  reducer.push(10);
  reducer.push(20);
  assert_eq!(reducer.get(), 30);

PIPELINE (Composition):
  filter → map → reduce
  Three-stage stream processing with zero allocation between stages

ARCHITECTURE OVERVIEW
================================================================================

LOCKFREE COORDINATION:
  Filter:  AtomicU64 (input_head + output_head)
  Map:     AtomicU64 (input_head + output_head)
  Reduce:  AtomicU64 (accumulator) + AtomicU64 (generation)

RING BUFFER DESIGN:
  Capacity: 4,096 entries (2^12 power-of-two)
  Wraparound: Atomic generation counter
  Modulo: Fast bitwise AND (pos & 0xFFF)
  Alignment: 64-byte cache lines

FUNCTION STORAGE:
  Type erasure via u64 bit-cast
  Retrieval via unsafe transmute (verified safe)
  Examples: fn(&T)->bool, fn(&T)->U, fn(T,T)->T

MEMORY LAYOUT:
  Filter/Map: 64B header + inline ring buffers (~8.2KB each)
  Reduce:     Exactly 64B (single cache line)
