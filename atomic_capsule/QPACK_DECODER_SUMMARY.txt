Static Table:
  • 61 predefined HTTP headers (RFC 9204 §A)
  • Stored globally as immutable constant
  • Shared across all decoder instances
  • Zero runtime overhead

Design Benefits:

  2. Multiple decoders share static table (cache-efficient)
  3. Per-connection state managed externally
  4. Fast index lookups (O(1) static, O(1) amortized dynamic)
