STATE MACHINE
================================================================================

                             ↓
                     on_pong_received()
                             ↓
IDLE ←───────────────────── PONG_RECEIVED
 ↑
 └─(is_timed_out)──→ Close connection

RFC 6455 Compliance:
  - Server sends Ping (opcode 0x9) every N seconds
  - Client responds with Pong (opcode 0xA) within timeout
  - Max payload: 125 bytes (control frame limit)
  - No Pong within timeout → close connection

RFC 6455 COMPATIBILITY
================================================================================

STANDARD: RFC 6455 - The WebSocket Protocol
SECTIONS: §5.5.2 (Ping), §5.5.3 (Pong)

COMPLIANCE:
  ✅ Ping sent with opcode 0x9
  ✅ Pong response with opcode 0xA
  ✅ Same payload echoed in pong
  ✅ Max payload 125 bytes (enforced by application)
  ✅ Timeout-based connection closure
  ✅ Monotonic operation semantics

EXAMPLE USAGE:

  let hb = WebSocketHeartbeatCapsule::new(
      Duration::from_secs(30),    // 30-second ping interval
      Duration::from_secs(10),    // 10-second timeout
  );

  // Check if time to send ping
  if hb.should_send_ping(Instant::now()) {
      send_ping_frame();            // RFC 6455 Ping (opcode 0x9)
      hb.on_ping_sent(Instant::now());
  }

  // Receive pong response
  if let Some(_) = receive_pong_frame() {    // RFC 6455 Pong (opcode 0xA)
      hb.on_pong_received(Instant::now());
  }

  // Detect timeout
  if hb.is_timed_out(Instant::now()) {
      close_connection();
  }
