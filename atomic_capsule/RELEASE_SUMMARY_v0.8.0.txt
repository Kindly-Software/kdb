================================================================================
KNOWN LIMITATIONS & FUTURE WORK
================================================================================

Deliberately Not Implemented (Design Decision):
  - Custom serialization extensions (use manual Serializer trait)
  - Auto-derive for custom types (use atomic_capsule_derive separately)
  - Version-aware serialization (manual versioning recommended)

Current Constraints:
  - Protobuf: Schema must be manually defined
  - Avro: Schema validation at runtime (v0.9.0: compile-time)
  - JSON5: Comments preserved in output (future: option to strip)

Future Roadmap:
  - v0.9.0: Compile-time Protobuf schema validation
  - v1.0.0: Stable API with long-term support guarantee
  - v1.1.0: Async serialization support (T5 Streaming)
