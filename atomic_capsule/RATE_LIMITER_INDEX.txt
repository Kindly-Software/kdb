Common Questions:
  Q: What's Q16.16 fixed-point?
  A: Integer encoding: value * 65536 = Q16.16
     Precision: 0.0000153 tokens
     Range: 0-65535.99998 tokens

  Q: Is it thread-safe?
  A: Yes, 100% lockfree, safe to share via Arc<RateLimiterCapsule>

  Q: How do I use it for multiple users?
  A: Store per-user instances in a lockfree hashmap (ConcurrentMapCapsule)

  Q: What's the latency?
  A: 80-130ns per operation (<150ns target, all tests pass)

  Q: Can I use fractional tokens?
  A: Yes, Q16.16 supports 0.0000153 token granularity
