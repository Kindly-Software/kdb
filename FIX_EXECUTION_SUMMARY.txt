================================================================================
TECHNICAL EXPLANATION
================================================================================

Why Cargo Ignores [profile.test] panic Settings:

1. Profile Hierarchy:
   - dev    → Used for normal builds and tests
   - test   → Real profile but panic setting ignored
   - bench  → Used for benchmark builds
   - release → Used for optimized builds

2. Cargo's Design Decision:
   - [profile.test] can override other settings (opt-level, etc.)
   - But [profile.test] panic is explicitly ignored
   - This prevents test/release inconsistencies
   - Tests must use [profile.dev] panic setting

3. Why Benchmarks Need panic = "unwind":
   - Criterion.rs catches panics to measure performance
   - It needs panic unwinding to work properly
   - [profile.bench] inherits from release (default unwind)
   - Keep release panic commented out for compatibility
